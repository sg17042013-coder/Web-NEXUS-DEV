# NEXUS DEV — web modernizada

- `index.html`: página principal.
- `css/styles.css`: diseño adaptable, neón y animaciones.
- `js/script.js`: menú y formulario de solicitudes.
- `assets/nexus-logo.svg`: logo temporal.
- `assets/nexus-photo.png`: aquí debes colocar la foto real de NEXUS.

**La foto real no estaba adjunta en el mensaje.** Guarda la imagen como `nexus-photo.png` y colócala dentro de `assets`. Si tiene otro nombre, cambia el `src` de la imagen en `index.html`.

El formulario prepara un texto para copiar en Discord; no envía datos automáticamente. Para publicar, sube todos los archivos y carpetas a un hosting estático.
